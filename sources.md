# Источники

1. **Numbers for Computing**, University of New Hampshire. https://cs400.cs.unh.edu/numbers/ — использован для определений систем счисления и общего объяснения перевода между основаниями.
2. **Base Conversion Process**, North Carolina State University. https://e115.engr.ncsu.edu/hardware/binary/base-conversion-process/ — использован для пошаговых примеров позиционной записи и перевода между двоичной и десятичной системами.
